# Telegram-бот «Мой удел в Торе»

Бот открывает те же три свитка, что и раздел игры «Мой удел в Торе»:

1. **Стих имени** — стих Танаха, который начинается на первую букву имени на иврите и кончается на последнюю (и стих, где встречается само имя; остальные стихи пары — по кнопке).
2. **Слово на день рождения** — запись книги Ребе «היום יום» на этот день.
3. **Глава рождения** — недельная глава субботы той недели, когда человек родился (в Израиле и за его пределами).

Разговор: язык (по языку Telegram, сменить — `/lang` или кнопкой) → мальчик/девочка (для форм «родился/родилась») → имя (бот сам пишет его буквами иврита, можно исправить на кнопочной клавиатуре или прислать на иврите) → дата рождения: обычная (и «после захода солнца») или еврейская (месяц, число, год) → место рождения → три свитка и ссылка на игру. Имя и дату можно пропустить.

Бот считает всё **тем же кодом, что и сайт**: `pasuk.js`, `hayomyom.js`, `lot.js` запускаются в песочнице (`node:vm`) с файлами `data/` и строками `locales/`. Поэтому бот всегда совпадает с игрой, а правки расчётов и текстов в игре сразу попадают в бота.

## Файлы

| Файл | Что это |
|---|---|
| `bot/core.mjs` | Разговор и три свитка, без сети: `handle(update, api)` |
| `bot/bot.mjs` | Запуск: long polling Telegram Bot API, без зависимостей |
| `bot/texts.json` | Строки бота на ru/uk/de/en (одинаковые ключи). Строки разделов игры (`lot.*`, `hy.*`, `pasuk.*`) берутся из `locales/` |
| `tests/bot.mjs` | `npm run test:bot`: тексты на всех языках и разговоры без сети |

## Запуск

1. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → имя и адрес бота → токен.
2. На сервере с Node.js 18+ (нужен весь репозиторий: бот читает `data/`, `locales/`, `content/` и скрипты игры):

   ```sh
   git clone https://github.com/TeacherRG/Koelet.git && cd Koelet
   TELEGRAM_BOT_TOKEN=123456:ABC... npm run bot
   ```

   `npm install` не нужен: у бота нет зависимостей. Команды меню (`/start`, `/lang`, `/privacy`, `/help`) бот сам выставляет на четырёх языках.

3. Чтобы бот работал постоянно — например, служба systemd `/etc/systemd/system/koelet-bot.service`:

   ```ini
   [Unit]
   Description=Koelet Telegram bot
   After=network-online.target

   [Service]
   WorkingDirectory=/opt/Koelet
   Environment=TELEGRAM_BOT_TOKEN=123456:ABC...
   ExecStart=/usr/bin/node bot/bot.mjs
   Restart=always
   DynamicUser=yes

   [Install]
   WantedBy=multi-user.target
   ```

   `systemctl enable --now koelet-bot`. Обновить: `git pull && systemctl restart koelet-bot`.

GitHub Pages бота запустить не может (там нет сервера) — нужен любой сервер или хостинг с Node.js, где процесс работает постоянно. Токен — только в переменной окружения, никогда в репозитории.

## Приватность

Бот ничего не пишет на диск и в лог (в лог — только сбои вызовов Telegram, без текста людей). Имя и дата живут в памяти, пока человек отвечает, и стираются, когда свитки открыты, или через сутки без ответа; в памяти остаётся только выбранный язык, до перезапуска. Сама переписка хранится в Telegram — это сказано в `/privacy`. В отличие от сайта, где ничего не покидает устройство, в боте имя и дата проходят через Telegram и сервер бота: это стоит помнить, приглашая в бота детей.

## Правки

- Новая строка — в `bot/texts.json` на всех четырёх языках (`npm run test:bot` проверяет ключи и `{{переменные}}`). Формы рода — `{м|ж}`, как в игре.
- Расчёты не дублируются: правьте их в `pasuk.js` / `hayomyom.js` / `lot.js`.
